# V6 evidence navigation

This folder contains actual browser output for the V6 motion contract. Client
creative acceptance remains separate from engineering verification. No deployment.

- P0: working hero/Atlas/network lab, including labeled early harness attempts.
- P1: integrated opening/navigation; P1/media corrects the P0 clipped-image test gap.
- P2: three-state scene captures and desktop/Arabic-phone/reduced recordings.
- P3: internal pages, selected-photo identity, back navigation and static fallback.
- P4/release: final build's responsive matrix, full desktop-wheel/Arabic-touch
  recordings, production public/V3 results, accessibility and browser trace.
- P4/interactions: real worlds, Atlas, service preview, planner, country carousel,
  network pause/static behavior and controlled native shared-transition samples.
- P4/atlas: sampled actual map-camera transitions and unchanged EN/AR geography.
- P4/cpu: normal/manual-reduced/SaveData first-click behavior under 4x CPU.
- MOTION_OWNERSHIP.md: animation owners, timelines and exact evidence scope.
- manifest.json: SHA-256 inventory of durable evidence, excluding the manifest itself.
- frontend-v2/public/brand/network/inventory.json (repository root): nineteen original
  profile-derived logo crops, source-page/classification/approval/provenance records.

Historical attempts remain labeled: P0 wrong-index/pause assumptions, P4 keyboard,
optimizer, hydration/focus defects, profile-overlap (confounded and excluded), and
path-cache-attempt (structural pass but failed performance closure). Older P4
final.json and desktop-trace.json.gz are the pre-pause build, not the release.
Use P4/release for the final build and performance outcome.

Full-page screenshots capture the document at one scroll position; offscreen
scroll-linked scenes can be at their authored entry state. Use scene start/mid/end
captures and the continuous recordings to assess those effects. Native shared
transition sample screenshots pause real browser animations at 0/400/799ms;
natural unpaused playback is shared-photo.webm. Capture overhead is not timing.
All timings are instrumented Windows Chromium observations, not encoding FPS or
physical-device certification. Original local output paths in JSON retain audit
history; adjacent durable files and this index are the portable delivery.
