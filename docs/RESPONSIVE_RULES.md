# Responsive rules — current candidate

Desktop, tablet and phone are authored compositions. Preserve TL-011 phone recovery,
desktop scenes and native scrolling at every width. V3 Lenis/pin/height eligibility
is superseded; [archived rules](archive/historical-material/pre-v1-consolidation/docs/RESPONSIVE_RULES.md)
retain context.

Review 320px and 360–430px phones, 768px tablet, 1024px/1440px desktop, plus short landscape.
Use long EN/TR/AR content. Require readable headings/captions, no document overflow,
coherent order, uncut critical UI and reachable menus. Preserve svh/dvh/safe-area behavior;
physical dynamic browser chrome needs device tests.

Phone Atlas index/caption baseline stay stable. Optional map controls retain 44px targets
and stationary geographic coordinates. Never mirror geography/photo meaning in Arabic.
Keep actual RTL, logical positioning and connected Arabic type. Preserve selection/journey
order across locales. Keep keyboard access, focus and labeled reorder-button alternatives.
Check 200% text zoom and short menus/forms when changing components. Retain practical
44px targets and current larger primary controls. Crops/focal points are viewport authored;
important text stays HTML. Essential content needs no hover or WebGL.

Motion follows [explicit choices](MOTION_SYSTEM.md) with useful reduction/media/capability
fallbacks. Exact executed coverage belongs in dated [QA](QA_RELEASE.md), not a universal
browser/device certification claim.
