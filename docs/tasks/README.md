# Task workflow

Current consolidation: [TL-016](TL-016-v1-baseline-consolidation.md), with the user's
[full request](TL-016-instructions.txt). Outcome: [status](../../PROJECT_STATUS.md) and
[report](../reports/TL-016-v1-baseline-consolidation.md).

Before significant work, use [TASK_TEMPLATE](TASK_TEMPLATE.md) to record outcome,
scope, constraints, acceptance and verification. Status: Planned → In Progress → Review
→ Complete; Superseded names its replacement. Completion requires evidence, a matching
[report](../reports/README.md) and status updates. Follow-ups require new authorization.

Prior TL-001–TL-015/TL-SYS records remain at stable paths for authority/recovery;
they do not authorize renewed deployment, orchestration or feature work.
[Historical index](../archive/historical-material/pre-v1-consolidation/docs/tasks/README.md)
preserves earlier annotations.
