The website currently feels too much like independent sections with restrained motion. This task is NOT a QA-only continuation and NOT a request to simply increase animation values.

Rebuild the presentation/experience layer around a much clearer UX architecture and then implement the Bronze Journey motion language on top of it.

- Türkiye-first
- award-caliber
- cinematic
- highly organized
- easy to understand
- interactive
- spatial on desktop
